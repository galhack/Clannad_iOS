## 保留的修复

- 原生剧情选择采用从零开始的序号，到选择点暂停快进，选项间隔 32 pt。
- 回看从最近对白打开，系统菜单/存档/设置界面隐藏原生浮层。
- Apple 显示循环减少无工作时的处理，并按系统热状态调整节奏。
- 损坏或不兼容存档保留诊断，不能用静默跳过代替兼容性。
- 菜单可用性仍遵守原版场景限制；回调被拒绝不等同于空间输入没有送达。

## 开源与数据边界

公开源码快照不带本地私密 Git 历史，不包含游戏本体、演示截图、原版手册、
提取的参考着色器、存档、密钥或描述文件。引擎为 MPL-2.0，外壳和工具为 MIT。
后备字体为 Noto Sans SC（SIL OFL 1.1），保留上游提交、散列、许可证及生成方式。
游戏自带本地字体仍优先读取，用户须自行购买并导入游戏。

源码校验：`python3 tools/check_source_only.py .`。
